Atajo: el francés se escribe como el latín y se pronuncia acortado

  • La escritura delata al pariente: table (mesa, como "tabla"), porte (puerta), temps (tiempo), mer (mar). Lo difícil es la pronunciación, así que escucha siempre el audio.
  • Las letras finales casi nunca suenan: petit = "ptí", vous = "vu", grand = "gran" (nasal).
  • El acento circunflejo marca una S que se perdió: forêt → floresta (bosque), hôpital → hospital, fête → fiesta.
  • -ción pasa a -tion, -dad pasa a -té: nation, liberté, vérité, université.
  • Falsos amigos hay pocos, pero son traicioneros: vienen marcados como "Falso amigo" (por ejemplo, ranger no es "rango", es "ordenar").

Género

le / l'masculino, azul
la / l'femenino, rojo

Delante de vocal o h muda el artículo se convierte en l', y entonces solo el color muestra el género. Las terminaciones -tion, -té, -ure suelen ser femeninas; -ment, -age suelen ser masculinas. Ojo: le lait (la leche), la mer (el mar), le sang (la sangre), la dent (el diente) tienen género distinto al español.
